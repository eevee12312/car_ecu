VR38DETT Real-Time Engine and Performance Simulator

A Python-based real-time simulator of the legendary **VR38DETT** engine from the Nissan GT-R. It emulates engine behavior, vehicle dynamics, turbo boost, and acceleration timing with joystick input, audio synthesis, and a modular architecture for tuning and expansion.

---

## 🚀 Features

- 🔧 **Dual Performance Modes**
  - `Stock`: Factory VR38DETT performance
  - `Tuned`: Increased boost, torque, HP, and higher top speed

- 🎧 **Engine Sound Synthesis**
  - Real-time RPM-based engine audio
  - Turbo flutter effects (optional)
  
- 🕹️ **Gamepad/Joystick Control**
  - Throttle, clutch, and manual gear shifting support
  - Smooth acceleration and deceleration

- 📊 **Live Telemetry**
  - RPM, speed (km/h), gear, boost (PSI), torque, horsepower
  - Peak RPM and top speed tracking
  - Engine temperature simulation

- 🏁 **Performance Benchmarking**
  - 0–60 mph (0–96.5 km/h) timer
  - ¼-mile (402m) elapsed time
  - Auto-logging to `log.txt` per run

- 🖥️ **Modular Dashboard Ready**
  - Integrates with PyQt6-based circular RPM gauge and digital speedometer
